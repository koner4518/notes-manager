# 📝 Notes Manager

A full-stack Notes Management application built using React.js, Node.js, Express.js, and MongoDB.

The application allows users to securely register and log in, create personal notes, view their notes, edit existing notes, and delete notes. Authentication is implemented using JWT, while passwords are securely hashed using bcrypt.

---

## 🚀 Features

### Authentication

- User registration
- User login
- Password hashing using bcrypt
- JWT-based authentication
- Protected routes
- Authorization for user-specific notes
- Logout functionality

### Notes Management

- Create notes
- View personal notes
- Edit notes
- Delete notes
- Automatic creation and update timestamps
- Fixed-size note cards
- Scrollable content for long notes

### User Interface

- Responsive design
- Interactive note cards
- Hover effects
- Loading states
- Error messages
- Mobile-friendly layout
- Clean and simple user interface
